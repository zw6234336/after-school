Design notes · 设计说明

作业星球

用一个 3D 太空场景，把每天的作业变成一次“给火箭加燃料、发射”的小任务；英语部分按美国小学 Common Core（CCSS ELA）的底层逻辑来组织。

1为三个人设计

同一个页面，要同时满足三方面：孩子愿意做、做的是“对的练习”、家长不费力就能布置和检查。后面所有设计都是从这三点推出来的。

🧒 孩子：愿意做

即时反馈、看得见的进度、做完有“仪式感”。错了不惩罚，只鼓励再试。

📚 学习：做对的练习

每道题对准一个具体能力（CCSS 标准）。阅读围绕一篇文章：读 → 答 → 找证据 → 说 → 写。

👪 家长：省心可控

改一份 homework.json 就能布置作业；报告直接告诉你哪项能力达标、哪道题第一次错了。

2游戏化：用一个比喻把作业串起来

不做“答题积分墙”，而是给作业一个孩子一眼能懂的故事：每完成一项作业，就给火箭加一点燃料；加满就发射。每个元素都对应作业里的一个真实概念。

作业里的概念场景里的样子为什么这样设计
科目 / 今天的一项大作业🪐 一颗星球（颜色区分）一眼看到今天有几块内容；点星球镜头飞过去，进入“专注模式”
一个小任务🌑 绕星球转的卫星，完成后变成 🌕 金色进度具体到“哪一个还没做”，也可以直接点卫星开始
今天的总进度🔥 中间火箭的燃料环 + 底部燃料条把零散任务汇成一个共同目标，“还差 3 项就能发射”
全部完成🚀 火箭发射 + 🎆 烟花 + 庆祝弹窗给“做完”一个明确的结束仪式，而不是无限刷题
答对一题⭐ 星星从题目飞进计数器 + 星球冒出粒子奖励就发生在答题的那一刻，因果关系清楚

3每一道题的反馈循环

核心原则：永远给孩子下一步可以做的事，不让他卡住；同时把第一次的回答留给家长看——这才是真实水平。

① 出题一次只显示一道；可以 🔊 听题、💡 看提示
② 作答选择 / 数字键盘 / 字母块 / 单词卡 / 排序 / 写作
③ 自动判断忽略大小写、全半角、多余空格；数字按数值比较
④ 记录第一次回答第一次错的题进入家长的错题本
✅ 答对一次答对 +2⭐，改正后答对 +1⭐，星星飞进计数器
🔍 阅读题：再找证据在文章里点出能证明答案的句子，一次找对 +1⭐
→ 自动进入下一题全部做完显示小结；任务完成卫星变金色
❌ 第 1 次答错“再想想～”，选择题划掉错误选项
❌ 第 2 次答错自动给出 💡 提示
❌ 第 3 次答错直接显示正确答案，“记住啦，下一题” —— 不让孩子卡死在一道题上

4英语：Common Core 的底层逻辑怎么变成产品

美国小学英语（ELA）不是按“课文”组织，而是按能力标准组织：每个技能都有一个代码，课堂、作业和成绩单都围绕这些标准展开。

RI领域：信息类阅读

1年级（K = 幼儿园）
.
1第 1 条：关键细节

同一条标准在 K–5 年级螺旋上升：RI.K.1 “在帮助下回答关键细节问题” → RI.3.1 “明确引用文本作为回答依据”。所以年级只要改代码里的数字。

标准驱动

每节课都有明确的学习目标，美国老师会把 “I can …” 写在黑板上。

每道题、每项作业都带标准代码，题目上方显示 🎯 I can answer questions about key details in a story. 和中文解释。

以文本为中心

阅读理解围绕一篇完整的短文，而不是零散的单句题。

读前：先认识生词卡；读中：点任意单词听发音、“Read to me” 逐句朗读高亮；读后：回答“只看文章就能回答”的问题。

文本证据（Text evidence）

CCSS 最核心的要求：回答要能在原文里找到依据，而不是凭印象。

答对后还有第二步：在文章里点出证明答案的句子。报告里单独统计“一次就找对证据”的比例。

阅读基础技能（Foundational skills）

低年级先打好拼读、音素意识和流利度的基础。

听音拼词（字母块，带其他元音做干扰）、押韵辨析；朗读按“我听示范 → 我们一起读 → 我自己读”的渐进释放，计算每分钟词数并对照年级目标。

读、写、说一体

同一个主题贯穿阅读、口语和写作。

今天的“最喜欢的季节”：读 Tom 和 Mia 的故事 → 用单词卡拼 My favorite season is spring. → 去问爸爸妈妈 → 写一句带 because 的观点。

标准化评分（Standards-based grading）

成绩单不是一个总分，而是每项标准的掌握程度。

家长报告按 6 个领域分组，每条标准显示 4 级：Exceeds 优秀 / Meets 达标 / Approaching 接近 / Beginning 起步。
CCSS 领域在作业星球里的交互今天的作业
🔤 RF 阅读基础字母块拼词、押韵、短元音辨析、朗读计时Ee：net · wet · vet · jet
📚 RL 文学阅读故事阅读 + 找证据、人物、复述What's Your Favorite Season?
🔬 RI 信息类阅读说明文阅读 + 找证据、步骤排序（示例：From Egg to Frog）
🧩 L 语言运用看图选词、分类、反义词、单词卡拼句型四季、hot/cold/cool/warm、It's spring.
✍️ W 写作写作题目 + 句子开头 + 实时检查清单My favorite season is ___ because ___.
🗣️ SL 听与说听力题自动播放、复述/对话打卡问大人 “What's your favorite season?”

答对后要在文章里点出证据句。
设计要点：答案和证据分两步。第一步检查“理解了没有”，第二步检查“能不能回到原文找依据”。证据句一开始不标出来，答对后整篇文章变成可点击的句子。

🧩 L.K.1

设计要点：同一个“点卡片”的动作，用在两种练习上：句型（It's spring.）和自然拼读（听 net，拼 n‑e‑t）。字母块里混入其他元音做干扰，练的正是“短元音 e”。

    6难度 = 支架 + 复杂度

    CCSS 里的“难”主要来自两件事：文本有多复杂，以及给了多少支架（scaffold）。三档难度按这个思路调整，而不是简单地“题目变多”。

    8细节上的取舍

    📱 平板优先

    大按钮、屏幕数字键盘（不弹系统键盘）、竖屏用底部面板；相机会偏移，让选中的星球始终在面板外的可见区域。

    📴 不依赖外部资源

    音效用 Web Audio 现场合成，朗读用系统自带语音，字体用系统字体，没有图片素材——打开就能用，国内网络也没问题。

    🧠 照顾注意力

    一次只显示一道题；英语题的鼓励语中英双语；系统设置了“减少动态效果”时关掉公转、流星等动画。

    🔒 家长保留控制

    可以锁定难度；打卡和写作需要家长点“检查通过”；清空进度要二次确认；报告可以打印。

    9已知局限和下一步

    • 朗读只测速度：页面听不出读错的词，得到的是每分钟词数（WPM），不是美国学校用的“每分钟读对词数”（WCPM），准确度靠家长在旁边听。下一步可以接语音识别。
    • 课本原文：课本故事需要家长自己填进 passage.text，目前用的是我写的练习故事。
    • 进度只在这台设备：换设备看不到。部署到 Cloudflare 后可以用 KV / D1 做云同步。
    • 可以继续做的：按周的历史记录和报告、多个孩子、错题自动生成复习题、拍照上传纸质作业让家长批注。
