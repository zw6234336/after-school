底层逻辑：先想清楚，再画页面

CCSS 对 ELA 提出了三个“转变”（Key Shifts），课堂上又有两条大家公认的规律。后面每个页面的设计都能追溯到这里。

Shift 1 · Complex text & academic language

📖 经常读有难度的文本，积累学术词汇

不只读为识字专门编的句子，而是读完整、有内容的文本，同一批词在单元里反复出现。

→ 页面 1、4：每个单元配一组同主题的书，词墙分“主题词”和“描述词”，学会的词会点亮。
Shift 2 · Evidence from text

🔍 读、写、说都用文本证据

问题只能从文章里找答案。回答完还要能指出“文章哪里这样说”。

→ 页面 4、6：答对后再点出证据句；用句子框架说 “The story says…”；写作用的是阅读里的词。
Shift 3 · Knowledge through nonfiction

🔬 用说明文积累知识

K–5 年级文学和信息类文本大约各占一半。同一个主题接连读几篇，背景知识会越积越多，读得也越来越轻松。

→ 页面 1：一周内先读故事、再读说明文、最后读儿歌，周五比较两篇（RI.K.9）。

🪢 阅读之绳：读懂 = 认字解码 × 语言理解

Scarborough 的“阅读之绳”和“阅读简单观点”（Simple View of Reading）是现在美国各州阅读教学（Science of Reading）的共同底层。CCSS 的 RF 标准对应下面三股，RL / RI / L 对应上面五股，SL 和 W 是把理解说出来、写出来。两组相乘，哪一组是 0，结果都是 0，所以每天两组都要练。

美国课堂叫 Gradual Release of Responsibility：老师先示范，再带着做，最后放手。使命任务也按这个节奏来，不直接把一道题扔给孩子。

🌀 同一条标准，年级螺旋上升

CCSS 的每条标准从 K 到 5 年级逐年加码。以观点写作 W.?.1 为例：

  1. W.K.1
    用画、口述、书写说出观点My favorite season is spring.
  2. W.1.1
    + 一个理由 + 结尾…because I like the flowers.
  3. W.2.1
    + 多个理由，用 because / and / also 连接，有结论句
  4. W.3.1
    + 开头引入、理由分组，用 since / for example 等连接，有结论
⚠️ 对照发现：现在普通档的写作要求“必须用 because、至少 8 个词”，这其实是一年级 W.1.1 的要求，K 年级的 W.K.1 只要求说出观点。建议普通档只要求说出观点，because 放到挑战档（见页面 6）。

  1. 核心问题（Essential Question）

    美国课堂的单元从一个问题出发，单元里的读和写都在回答它。孩子知道为什么要学，家长也知道这几周在学什么。

  2. 文本组（Text set）

    同一主题配故事、说明文和儿歌，文学和信息类大约各占一半，对应第三个转变“用说明文积累知识”。读第二篇时已经有了背景知识，理解起来更快。

  3. 词墙（Word wall）

    主题词和描述词分开放。一个词在阅读、拼句、写作里都答对过才会点亮，对应 L.K.6“用上学过的词”。

  4. 一周的顺序

    每天一个重点标准，按“词 → 句 → 故事 → 说明文 → 比较”的顺序往上走，周五做 RI.K.9“比较同一主题的两篇文本”。

  5. 单元任务（Performance task）

    单元结束时做一个读、写、说综合的作品，保存在家长报告的“学习证据”里，比分数更直观。

    今天的任务分成“认字解码”和“语言理解”两组，各自显示进度。家长一眼能看出今天的练习偏向哪一组，如果哪天全是拼读、没有阅读，也很容易发现。

  1. 音素格（Elkonin boxes）

    一格对应一个音，不是一个字母（比如 sh 只占一格）。点一下格子先听到这个音，再看到字母：先练 RF.K.2d 听出每个音，再练 RF.K.3 字母和发音对应。元音格用不同颜色标出来。

  2. 连读滑条（Blending）

    圆点从左滑到右，格子依次亮起，最后读出整个词。把几个音连成一个词是解码最核心的动作，美国课堂叫 blending。

  3. 单词链

    每次只换一个音（RF.K.2e 替换音素），换了哪一格，哪一格就闪一下。这样孩子会去注意形近词之间不同的那个字母（RF.K.3d），而不是只看整体字形瞎猜。

  4. 可解码句子（Decodable text）

    马上在句子里用上今天的音：除了学过的拼读规律，只有少量“心形词”，也就是要整体记住的高频词，比如 The、is。

RL.K.1RL.K.2RL.K.4L.K.1f
  1. 三遍读，每遍一个目标

    第 1 遍只听，说出大意（RL.K.2）；第 2 遍找关键细节（RL.K.1）；第 3 遍弄懂生词（RL.K.4）。每遍只问这一类问题，注意力不会分散。

  2. 文本放在中间，常驻屏幕

    问题只能从文章里找答案（text-dependent questions），不问“你喜欢哪个季节”这类不看文章也能答的题。第 3 遍时生词会高亮出来。

  3. 证据两步走

    先选答案，再点出证明答案的句子。这是第二个转变“用文本证据说话”在 K 年级的样子，到三年级会变成“明确引用原文”（RL.3.1）。

  4. 句子框架

    K 年级要求在共同活动中说出完整的句子（L.K.1f）。框架把“答案 + 证据”都放进去，孩子说一遍，家长听一遍。

  5. 分层提示

    K 年级标准原文写着“with prompting and support”（在提示和帮助下）。所以提示分三级，从最轻的开始给：再听一遍 → 圈出相关段落 → 标出关键词。用到第几级会记进报告。

  1. 示范 → 合声读 → 独立读

    先听标准示范，再跟着高亮一起读（choral reading），最后自己读并计时。如果跳过示范直接计时，孩子会只顾着读快。

  2. 家长点出读错的词

    页面本身听不出孩子哪个词读错了，家长在旁边点一下就行。这样能算出准确率和“每分钟读对词数”（WCPM，DIBELS 等美国学校测评用的就是这个指标），比现在只算总速度（WPM）更准。

  3. 准确率比速度重要

    RF.K.4 要求的是“有目的、能理解地读”，K 年级没有段落朗读的速度常模（Hasbrouck & Tindal 常模从一年级开始），所以准确率放在第一位，速度只作参考。准确率还能反过来判断文本难度：≥ 95% 可以自己读，90–94% 需要大人陪读，低于 90% 说明这篇太难，应该换简单一点的。

  4. 读完马上问一道题

    防止孩子读得很顺却没读懂。题目只能从刚读的文本里找答案。

RFRLLWSL
  1. 按阅读之绳的两组汇总

    解码弱和理解弱需要的帮助完全不同：解码弱要多做拼读练习，理解弱要多听多聊、积累词汇和背景知识。报告先给出这两组的结论。

  2. 每条标准一个 4 级

    和美国的标准化成绩单（standards-based report card）一样：Exceeds 优秀 / Meets 达标 / Approaching 接近 / Beginning 起步，不给总分。每条下面写一句具体表现，比如“warm ↔ cool 还会混”。

  3. 学习证据（Evidence of learning）

    写的句子和朗读录音都原样保存，比分数更能说明问题，也方便发给老师看。录音需要家长同意后才保存。

  4. 记录用了几级提示

    K 年级的很多标准本来就允许在帮助下完成，所以报告会写清楚用了哪一级提示。下一步的目标是不用提示独立完成。

  5. 只给一个下一步

    挑出最弱的一条标准，给一个 3 分钟能玩完的家庭游戏，第二天的热身再练一次，形成“发现 → 练习 → 复查”的循环。
